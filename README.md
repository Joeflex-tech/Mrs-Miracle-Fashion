# Mrs Miracle Fashion

Premium women's fashion e-commerce project focused on bags and footwear.

## Stack

React · Vite · Node.js · Express · PostgreSQL

## Project status

Portfolio / development project. This repository contains the source structure for the Mrs Miracle Fashion storefront and backend.

## Structure

- `frontend/` — React + Vite storefront and customer/admin interfaces
- `backend/` — Express API, authentication, products, orders, payments and uploads
